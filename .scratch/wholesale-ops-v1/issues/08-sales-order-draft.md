# 08 — 销售单草稿

**What to build:** 让销售为自己负责的客户创建、编辑和删除销售单草稿，使用真实 SKU 与可用量形成一张可继续确认的交易记录。

**Blocked by:** 04 — 客户资料与负责人数据边界；07 — 期初库存导入与库存查询

**Status:** ready-for-agent

- [ ] 销售可以为自己负责且启用的客户创建销售单草稿；老板可以为任意启用客户创建草稿。
- [ ] 草稿支持多个 SKU 明细，每行选择启用 SKU、填写正整数数量和最多两位小数的人民币成交价。
- [ ] 选择 SKU 时显示参考售价、库存单位和当前可用量；库存不足可以保存草稿但必须明确提示风险。
- [ ] 系统计算每行小计和销售单成交金额，金额计算使用定点口径而非浮点误差结果。
- [ ] 草稿保存客户名称、联系人、地址、客户负责人和账期等交易快照，后续客户资料变化不改写草稿快照。
- [ ] 创建者和老板可以编辑或删除草稿；其他销售、仓库和财务不能访问编辑能力。
- [ ] 销售单列表按权限显示，并支持编号、客户、客户负责人、履约状态和日期筛选。
- [ ] 离开有未保存修改的编辑页时给出提示，提交中阻止重复保存且校验失败保留输入。
- [ ] 创建、编辑和删除草稿写入业务审计，并与销售单变更保持事务原子性。
- [ ] 自动化测试覆盖客户数据范围、停用资料、整数和金额校验、快照稳定性、总额计算、草稿权限及审计。
