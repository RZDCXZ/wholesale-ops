# 05 — SKU Excel 导入

**What to build:** 让老板通过固定模板批量预览并导入 SKU，在出现任何错误时保持数据库不变，同时建立客户和期初库存后续可复用的导入处理接缝。

**Blocked by:** 03 — SKU 资料管理

**Status:** resolved

- [x] 老板可以下载包含正式字段和示例说明的 SKU `.xlsx` 模板。
- [x] 上传只接受 `.xlsx`，限制为不超过 10 MB 和 2,000 行；不接受宏，不计算公式，不保存原始上传文件。
- [x] 服务端解析第一张指定工作表，并对 SKU 编码、名称、分类、库存单位、参考售价、预警值和启用状态逐行校验。
- [x] 预览分别显示可导入行和错误行，错误包含行号、字段和可理解原因。
- [x] 文件内重复 SKU 编码、数据库既有编码、缺失字段、非法整数、非法金额和公式值均被拦截。
- [x] 任意一行有错误时确认导入保持禁用，数据库和业务审计均不产生部分结果。
- [x] 全部通过后由老板确认，所有 SKU 和一条导入业务审计在单一事务中写入。
- [x] 非老板不能上传、预览、确认或复用预览令牌，确认阶段必须重新验证操作者和预览内容的有效性。
- [x] 导入页面覆盖上传中、解析失败、错误预览、全部通过、重复提交和成功结果状态。
- [x] 自动化测试覆盖合法文件、空文件、错误工作表、限制超标、逐类字段错误、整批回滚以及成功导入。

## Answer

已完成老板专用的 SKU Excel 导入工作台：可下载带正式字段与填写说明的 `.xlsx` 模板，服务端验证 OOXML 工作簿类型、10 MB/2,000 行限制、首张固定工作表、精确表头、宏、公式、字段格式、文件内重复及数据库既有编码，并在一次预览中汇总全部行级错误。错误批次不能确认；合法预览使用绑定操作者、带签名且限时的令牌，确认时重新验证权限、有效期和 SKU 编码，所有 SKU、确认记录和一条导入业务审计在单一事务内写入，重复确认与预览后冲突均被阻止。原始文件和解析行不会持久化。

正式页面覆盖上传中、解析失败、错误/合法预览、确认中、临时确认失败可重试、令牌失效、重复提交和成功结果，桌面与 390px 移动宽度均完成验收。Vitest/Testcontainers 覆盖模板、格式与限制、逐类字段错误、混合错误汇总、权限和令牌、并发冲突、事务回滚与成功审计；Playwright 覆盖老板完整导入、临时失败恢复、非老板拒绝和移动端无页面级溢出。
