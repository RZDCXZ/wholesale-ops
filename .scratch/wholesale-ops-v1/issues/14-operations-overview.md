# 14 — 经营总览

**What to build:** 让老板从真实销售、收款、应收和库存数据理解当天经营结果与风险，并能从指标进入相应明细。

**Blocked by:** 12 — 部分收款与自动结清

**Status:** ready-for-agent

- [ ] 经营总览只对老板开放，其他角色登录后进入各自工作首页且不能直接读取老板指标。
- [ ] 今日销售额按中国标准时间汇总当天完成出库的销售单成交金额。
- [ ] 今日收款额按中国标准时间汇总当天登记且未撤销的有效收款金额。
- [ ] 未收金额等于全部未结清应收的未收金额合计，逾期金额等于全部逾期应收的未收金额合计。
- [ ] 库存预警展示可用量小于或等于预警值的启用 SKU 数量和明细，不使用现存量替代可用量。
- [ ] 收款趋势按最近三十个自然日和收款日期汇总有效收款，撤销收款不计入有效金额。
- [ ] 指标卡和库存预警入口可以进入已经应用相应筛选条件的销售单、应收或库存页面。
- [ ] 页面覆盖加载、无数据和服务失败状态，不加入成本、毛利、利润、采购或应付指标。
- [ ] 金额、日期、状态和图表文案符合设计 PRD，1440px 与 390px 下没有阻断查看的布局问题。
- [ ] 自动化测试使用跨中国标准时间日期边界的固定时钟验证所有指标口径、撤销影响、权限和下钻筛选。
