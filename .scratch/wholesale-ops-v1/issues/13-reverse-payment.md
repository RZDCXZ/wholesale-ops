# 13 — 撤销收款

**What to build:** 让财务或老板用只追加的反向记录纠正错误收款，保留原收款事实并正确恢复未收金额、结算状态和逾期状态。

**Blocked by:** 12 — 部分收款与自动结清

**Status:** ready-for-agent

- [ ] 财务或老板可以从有效收款记录发起撤销，并必须填写非空原因。
- [ ] 撤销确认说明原收款金额、撤销后累计收款、未收金额和预期结算状态。
- [ ] 撤销不会编辑或删除原收款，而是创建明确关联原记录的反向记录。
- [ ] 撤销成功后累计有效收款和未收金额恢复，应收根据新余额变为待收款、部分收款或已结清。
- [ ] 恢复未收金额后，逾期状态按当前日期和原到期日重新计算。
- [ ] 一笔收款最多成功撤销一次；反向记录不能再次撤销，重复请求返回清楚结果且不重复改变金额。
- [ ] 财务和老板以外角色不能撤销收款；销售看到的相关收款进度同步更新但不显示操作入口。
- [ ] 反向记录、应收金额与状态更新、业务审计在同一数据库事务中完成。
- [ ] 应收详情按时间清楚展示原收款及其撤销关系，不使用删除线以外的含糊表现代替文字状态。
- [ ] 自动化测试覆盖已结清后撤销、部分收款撤销、重复撤销、权限、原因校验、逾期恢复和事务回滚。
