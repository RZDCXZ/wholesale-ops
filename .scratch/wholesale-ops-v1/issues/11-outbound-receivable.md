# 11 — 整单出库并生成应收

**What to build:** 让仓库从待出库工作台完成一次完整交付，原子扣减现存量和预占量、记录库存活动并生成一笔经营应收，同时严格隐藏价格与应收信息。

**Blocked by:** 09 — 确认销售单并预占库存

**Status:** ready-for-agent

- [ ] 老板和仓库可以查看全部已确认待出库销售单；销售和财务没有待出库工作台访问权限。
- [ ] 仓库只看到履约所需的销售单编号、SKU、数量、库存单位，以及客户名称、联系人、电话和地址快照。
- [ ] 仓库页面和服务端响应不包含成交价、销售单成交金额、应收或收款信息。
- [ ] 出库确认清楚说明将交付的全部 SKU 与数量；首版没有部分数量、欠货或分批出库入口。
- [ ] 服务端出库时重新验证销售单为已确认、所有预占完整存在且操作者有权执行。
- [ ] 出库成功后销售单变为已出库，对应现存量和预占量同时减少，库存活动记录可追溯到销售单。
- [ ] 系统按销售单全部成交金额生成且只生成一笔应收，到期日按出库日加销售单账期快照计算。
- [ ] 销售单状态、数量变化、库存活动、应收和业务审计在同一数据库事务中完成，任一失败则全部回滚。
- [ ] 重复出库、已取消销售单出库以及取消与出库并发竞争均只能产生一个合法终态。
- [ ] 自动化测试覆盖仓库隐私边界、现结和有账期到期日、数量变化、单一应收、重复提交、事务回滚和状态竞争。
