# 19 — 作品集展示材料

**What to build:** 基于最终可运行应用制作一组无需在线部署也能清楚证明业务理解、交互质量和工程交付能力的个人网站展示材料。

**Blocked by:** 18 — 公开仓库交付

**Status:** ready-for-agent

- [ ] 制作一张销售单确认、库存预占、整单出库、生成应收、部分收款和结清关系清楚的流程图。
- [ ] 选取 6 至 10 张关键截图，至少覆盖角色差异、销售单确认、库存数字联动、应收收款、导入错误和经营总览。
- [ ] 截图使用确定性演示数据和一致浏览器尺寸，不包含真实个人资料、真实凭据、开发工具或无关桌面信息。
- [ ] 制作 60 至 90 秒结果导向短视频，快速说明原问题、核心闭环、异常拦截和作品性质。
- [ ] 制作 5 至 8 分钟完整演示视频，按固定路径展示登录、销售单、预占、出库、应收、收款、撤销、经营总览、权限和导入错误。
- [ ] 视频中的库存、应收、收款和经营指标数字前后一致，重复录制前通过演示重置恢复确定状态。
- [ ] 展示材料包含公开仓库入口、技术栈、自动检查结果和本地复现说明，但不暗示存在在线演示。
- [ ] 所有公开文案明确声明数据虚构、未经真实客户验证、不是财税系统，并避免未经验证的效率或成本承诺。
- [ ] 展示材料使用“批发经营台账 / Wholesale Ops”及领域词汇中的正式术语，不宣传为完整 ERP。
- [ ] 将可直接用于个人网站的最终图片、视频封面、说明文案和媒体清单整理为可交付成果。
