# 10 — 取消销售单并释放预占

**What to build:** 让销售或老板在出库前填写原因取消已确认销售单，原子释放全部预占并永久保留销售单和取消轨迹。

**Blocked by:** 09 — 确认销售单并预占库存

**Status:** ready-for-agent

- [ ] 销售可以取消自己负责客户的已确认销售单，老板可以取消任意已确认销售单。
- [ ] 取消对话框说明将释放的 SKU 和预占数量，并要求填写非空取消原因。
- [ ] 取消成功后销售单状态变为已取消，现存量不变、预占量减少、可用量相应恢复。
- [ ] 状态变化、预占释放、库存活动记录和业务审计在同一数据库事务中完成。
- [ ] 已取消销售单永久保留且不能重新启用、编辑、删除或再次取消。
- [ ] 草稿和已出库销售单不能通过取消入口处理；无权销售不能取消其他负责人客户的销售单。
- [ ] 并发取消或取消与出库竞争时只有一个合法状态转换成功，失败方得到清楚的当前状态提示。
- [ ] 取消后 SKU 库存页、销售单详情和业务审计展示一致的最新结果。
- [ ] 取消失败时不产生部分预占释放或孤立审计记录。
- [ ] 自动化测试覆盖权限、必填原因、数量恢复、非法状态、重复取消、事务回滚和并发状态竞争。
