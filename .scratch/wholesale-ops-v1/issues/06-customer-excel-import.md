# 06 — 客户 Excel 导入

**What to build:** 让老板复用导入工作流批量创建客户，并在写入前验证唯一客户编码、客户负责人和默认账期，保持整批原子性。

**Blocked by:** 04 — 客户资料与负责人数据边界；05 — SKU Excel 导入

**Status:** ready-for-agent

- [ ] 老板可以下载包含正式字段和示例说明的客户 `.xlsx` 模板。
- [ ] 客户导入沿用文件大小、行数、宏、公式、原文件保存和第一张指定工作表等统一导入限制。
- [ ] 服务端逐行校验客户编码、名称、联系人、电话、地址、客户负责人、默认账期和启用状态。
- [ ] 客户负责人必须匹配启用销售账号；默认账期必须为现结或合法非负整数天数。
- [ ] 文件内重复客户编码、数据库既有编码、缺失字段和无效负责人均显示具体行及原因。
- [ ] 任意错误存在时整批不写入；全部通过后客户和导入业务审计在单一事务中写入。
- [ ] 导入结果遵守既有客户数据边界，不能借导入接口给销售分配越权客户或绕过老板权限。
- [ ] 重复确认同一预览不会重复创建客户，并返回明确的已处理或失效提示。
- [ ] 页面状态和视觉复用已建立的导入工作流，不引入第二套不一致交互。
- [ ] 自动化测试覆盖客户特有校验、负责人状态变化、权限失败、整批回滚和成功导入。
