# 07 — 期初库存导入与库存查询

**What to build:** 让老板用固定模板为 SKU 建立可追溯的期初库存，让授权用户查看现存量、预占量、可用量、库存预警和库存流水。

**Blocked by:** 05 — SKU Excel 导入

**Status:** resolved

- [x] 老板可以下载期初库存模板，并通过统一导入工作流上传、预览和确认。
- [x] 每行通过 SKU 编码关联启用 SKU，数量必须是非负整数；未知、重复或停用 SKU 被逐行指出。
- [x] 任意错误存在时不写入任何库存；全部通过后期初库存、库存流水和业务审计在单一事务中生成。
- [x] 系统一旦存在销售库存活动就拒绝再次导入期初库存，不能把该入口当作库存调整工具。
- [x] 库存页对每个 SKU 展示库存单位、现存量、预占量、可用量、预警值和库存状态，并说明可用量计算口径。
- [x] 库存预警只针对启用 SKU，规则为可用量小于或等于预警值。
- [x] 库存流水为只追加记录，至少可按 SKU、动作类型和日期筛选，并能追溯到期初库存来源。
- [x] 老板和仓库可以查看全部库存与流水；销售在选择 SKU 时只能看到业务所需可用量；财务无权访问库存页。
- [x] 系统不存在直接编辑现存量的界面或服务端入口。
- [x] 自动化测试使用真实 PostgreSQL 验证整批事务、重复导入、活动后禁入、数量口径、预警计算和权限边界。

## Answer

已完成固定模板期初库存导入、逐行预览校验、确认事务、重复与销售库存活动禁入、只追加库存流水和业务审计。库存与流水页提供角色鉴权、组合筛选、排序、分页、响应式布局和期初导入来源详情；SKU 详情展示最近库存流水，销售页面只呈现业务所需可用量。真实 PostgreSQL 集成测试覆盖公式拒绝、整批回滚、重复导入、活动后禁入、预警与权限边界；全量 Vitest、Playwright、类型检查、lint 和生产构建均通过。
