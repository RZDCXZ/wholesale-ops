# 15 — 按权限和筛选条件导出

**What to build:** 让授权用户把当前可见的销售单、应收和库存流水导出为 `.xlsx`，保证导出内容严格遵守角色、数据范围和页面筛选，并留下业务审计。

**Blocked by:** 12 — 部分收款与自动结清

**Status:** resolved

- [x] 老板和销售可以按各自数据范围导出销售单，销售导出中不包含其他负责人客户的数据。
- [x] 老板和财务可以导出应收；销售如有导出入口也只能包含自己负责客户的受限收款进度字段；仓库不能导出应收。
- [x] 老板和仓库可以导出库存流水，导出中不包含成交价、应收或收款字段。
- [x] 导出结果应用与页面一致的搜索、状态、负责人、日期和其他当前筛选条件，而不是导出全部数据库记录。
- [x] 工作簿使用正式中文列名、稳定的编码与日期格式、人民币金额口径和整数数量口径。
- [x] 导出使用服务端重新解析的筛选参数和当前会话权限，不能信任客户端传入的任意用户或数据范围。
- [x] 每次成功导出都写入业务审计，包含操作者、导出类型、时间和必要筛选摘要。
- [x] 系统不保存导出文件或建立导出历史中心；生成失败不留下成功审计。
- [x] 大于空结果的导出有明确行为；无可导出记录时给出清楚反馈，不生成误导性的完整数据文件。
- [x] 自动化测试解析生成的工作簿验证字段、筛选、权限和业务审计，不依赖非契约性工作簿元数据。

## Answer

- 已为销售单、应收和库存流水增加服务端 `.xlsx` 导出与列表页“导出当前筛选”入口；服务端重新解析白名单筛选参数，并基于当前会话复用既有角色和数据范围查询。
- 销售只能导出当前负责客户的销售单；应收导出只对老板和财务开放；库存流水导出只对老板和仓库开放，工作簿不包含成交价、应收或收款字段。
- 三类工作簿使用正式中文列名、人民币元数值格式、整数数量与中国标准时间日期格式；空结果返回清楚反馈，不生成文件。
- 每次成功导出写入包含操作者、导出类型、时间、记录数与筛选摘要的业务审计；工作簿生成、权限或空结果失败不写入成功审计，也不保存导出文件或建立历史中心。
- 已通过解析工作簿的 PostgreSQL 集成测试、服务端筛选参数测试和真实登录下载的 Playwright 旅程，覆盖筛选、角色权限、销售数据范围、空结果、生成失败、审计与 1440px/390px 页面布局。
