# 15 — 按权限和筛选条件导出

**What to build:** 让授权用户把当前可见的销售单、应收和库存流水导出为 `.xlsx`，保证导出内容严格遵守角色、数据范围和页面筛选，并留下业务审计。

**Blocked by:** 12 — 部分收款与自动结清

**Status:** ready-for-agent

- [ ] 老板和销售可以按各自数据范围导出销售单，销售导出中不包含其他负责人客户的数据。
- [ ] 老板和财务可以导出应收；销售如有导出入口也只能包含自己负责客户的受限收款进度字段；仓库不能导出应收。
- [ ] 老板和仓库可以导出库存流水，导出中不包含成交价、应收或收款字段。
- [ ] 导出结果应用与页面一致的搜索、状态、负责人、日期和其他当前筛选条件，而不是导出全部数据库记录。
- [ ] 工作簿使用正式中文列名、稳定的编码与日期格式、人民币金额口径和整数数量口径。
- [ ] 导出使用服务端重新解析的筛选参数和当前会话权限，不能信任客户端传入的任意用户或数据范围。
- [ ] 每次成功导出都写入业务审计，包含操作者、导出类型、时间和必要筛选摘要。
- [ ] 系统不保存导出文件或建立导出历史中心；生成失败不留下成功审计。
- [ ] 大于空结果的导出有明确行为；无可导出记录时给出清楚反馈，不生成误导性的完整数据文件。
- [ ] 自动化测试解析生成的工作簿验证字段、筛选、权限和业务审计，不依赖非契约性工作簿元数据。
