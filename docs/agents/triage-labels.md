# Triage 标签

Engineering skills 使用五种标准 triage 角色。本文件将这些角色映射到当前仓库 issue tracker 使用的实际标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 AFK agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要由人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个角色时，例如“应用 AFK-ready triage 标签”，应使用上表中对应的实际标签字符串。

如果仓库以后采用不同的标签词汇，请修改表格右侧的“本仓库使用的标签”列。
